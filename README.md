# bema

A [Memos](https://usememos.com) client for Android and iOS built on a single Kotlin
Multiplatform shared module. Android uses Jetpack Compose; iOS uses UIKit.

## Layout

| Path | Contents |
| --- | --- |
| `app/androidApp` | Android entry point |
| `app/sharedLogic` | Shared business logic (Android library + iOS framework) |
| `app/iosApp` | UIKit app; the Xcode project is generated by XcodeGen from `project.yml` |

Dependency versions live in [`gradle/libs.versions.toml`](./gradle/libs.versions.toml).

## Prerequisites

- JDK 17+
- Android SDK: compileSdk 37 (via `ANDROID_HOME` or `local.properties`)
- iOS only: macOS with Xcode 16+ and XcodeGen (`brew install xcodegen`)

## Build

```bash
./gradlew androidCheck                  # shared-module tests + debug APK
./gradlew :app:androidApp:installDebug  # install on a connected device

cd app/iosApp && xcodegen generate
xcodebuild -scheme Bema -sdk iphonesimulator build
```

## CI and releases

[`ci.yml`](./.github/workflows/ci.yml) validates the Gradle wrapper, runs `androidCheck`,
and builds the iOS app; [`codeql.yml`](./.github/workflows/codeql.yml) runs CodeQL
quality/security analysis.

[release-please](https://github.com/googleapis/release-please) turns
[Conventional Commits](https://www.conventionalcommits.org/) into a release PR.
Merging it bumps `version.txt` + `CHANGELOG.md` and tags `vX.Y.Z`, which makes
[`release.yml`](./.github/workflows/release.yml) attach a signed APK and an unsigned
`.xcarchive` to the GitHub Release. The Android job requires the `ANDROID_KEYSTORE_*`
secrets and fails without them, since an unsigned APK cannot be installed.
